# Дневник — версия для телефона

Готовый PWA-пакет на основе исходного `index.html`.

В комплекте:
- `index.html` — исходный дневник;
- `manifest.webmanifest` — установка как приложения;
- `sw.js` — офлайн-кэш;
- иконки из присланного изображения;
- папка `music/` с тремя присланными MP3.

## Как установить

### Android
1. Размести эту папку на HTTPS-сайте.
2. Открой сайт в Chrome.
3. Выбери «Установить приложение» / «Добавить на главный экран».

### iPhone
1. Открой сайт в Safari.
2. Нажми «Поделиться».
3. Выбери «На экран „Домой“».
4. Нажми «Добавить».

После первого полного открытия основные файлы и музыка будут доступны из кэша офлайн.

Важно: для установки PWA с обычного сайта нужен HTTPS. `file://` для этого не подходит.
